# ESP32-S3 Super Mini SKADIS Case

A two-part snap case that hangs an ESP32-S3 Super Mini board edge-on from an IKEA SKADIS pegboard, USB-C end up. The tray holds the board on a ledge, and the lid clicks into the tray walls. A wide window in the lid gives easy access to the BOOT and RST buttons. The fit is checked against a STEP model of the board.

![Turntable render](<ESP32-S3 Super Mini SKADIS Case.gif>)

## Files

| File | What |
|---|---|
| `.3mf` | Tray and lid, laid out to print with no supports |
| `.step` | Tray and lid, assembled |
| `.FCStd` | FreeCAD file with the tray and lid as solids |

No hardware needed.

# CLUE nRF52840 SKADIS Mount

Hangs the [Adafruit CLUE - nRF52840 Express with Bluetooth LE](https://www.adafruit.com/product/4500) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<4500 CLUE nRF52840 SKADIS Mount.gif>)

Mounted edge: The edge with the gold rings, screwed through the two large end rings, with the display facing out.

The end rings are 4 mm, so use a washer under each M2 screw head.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

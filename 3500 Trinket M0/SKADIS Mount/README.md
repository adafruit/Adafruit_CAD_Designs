# Trinket M0 SKADIS Mount

Hangs the [Adafruit Trinket M0 - for use with CircuitPython & Arduino IDE](https://www.adafruit.com/product/3500) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<3500 Trinket M0 SKADIS Mount.gif>)

Mounted edge: The short edge opposite the USB port, with the parts facing out.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

| Part | Qty |
|---|---|
| M2 heat set insert, for a 3.3 mm hole up to 3.3 mm deep | 2 |
| M2 x 4 screw | 2 |

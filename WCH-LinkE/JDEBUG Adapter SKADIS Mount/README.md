# WCH-LinkE JDEBUG Adapter SKADIS Mount

Hangs the [WCH-LinkE JDEBUG Adapter](<../JDEBUG Adapter>) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the adapter's KiCad STEP export.

![Turntable render](<WCH-LinkE JDEBUG Adapter SKADIS Mount.gif>)

Mounted edge: the short edge beside the probe socket, so the JDEBUG ribbon leaves from the free end.

The WCH-LinkE stands about 50 mm out from the board face, so leave that much room beside the mount on the panel.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

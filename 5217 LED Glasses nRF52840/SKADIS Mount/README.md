# LED Glasses nRF52840 SKADIS Mount

Hangs the [Adafruit LED Glasses Driver - nRF52840 Sensor Board](https://www.adafruit.com/product/5217) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<5217 LED Glasses nRF52840 SKADIS Mount.gif>)

Mounted edge: The short edge by the USB-C port, with the parts facing out and the nRF52840 module at the far end.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

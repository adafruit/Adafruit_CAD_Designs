# PyPortal SKADIS Mount

Hangs the [Adafruit PyPortal - CircuitPython Powered Internet Display](https://www.adafruit.com/product/4116) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<4116 PyPortal SKADIS Mount.gif>)

Mounted edge: The long edge, with the display facing out and micro-USB pointing away from the panel.

The board's holes are 3.0 mm, so use washers under the M2 screw heads.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

| Part | Qty |
|---|---|

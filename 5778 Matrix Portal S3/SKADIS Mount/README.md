# Matrix Portal S3 SKADIS Mount

Hangs the [Adafruit Matrix Portal S3 CircuitPython Powered Internet Display](https://www.adafruit.com/product/5778) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<5778 Matrix Portal S3 SKADIS Mount.gif>)

Mounted edge: The long edge opposite the USB-C, top face against the arms, so the USB-C points up and the STEMMA QT and JST ports face out.

The screws go in from the back of the board, the HUB75 socket side. The arms have shallow pockets for the small parts on the top face, so the board sits flat.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

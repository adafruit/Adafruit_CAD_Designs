# MONSTER M4SK SKADIS Mount

Hangs the [Adafruit MONSTER M4SK - DIY Electronic Eyes Mask](https://www.adafruit.com/product/4343) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<4343 MONSTER M4SK SKADIS Mount.gif>)

Mounted edge: The bottom edge by the nose cutout, with the displays facing out.

The board's holes are 3.0 mm, so use washers under the M2 screw heads.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

| Part | Qty |
|---|---|

# MagTag SKADIS Mount

Hangs the [Adafruit MagTag - 2.9" Grayscale E-Ink WiFi Display](https://www.adafruit.com/product/4800) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<4800 MagTag SKADIS Mount.gif>)

Mounted edge: The short edge away from the USB-C, with the e-ink facing out.

Remove the magnet feet first: the mount uses two of their corner holes. The holes are 4.25 mm, so the M2 screws need washers.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

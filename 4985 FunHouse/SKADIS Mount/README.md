# FunHouse SKADIS Mount

Hangs the [Adafruit FunHouse - WiFi Home Automation Development Board](https://www.adafruit.com/product/4985) edge-on from an IKEA SKADIS pegboard. The board's standoffs rest on the arm, and M3 screws go up through it. Standoff positions are checked against the Adafruit STEP model.

![Turntable render](<4985 FunHouse SKADIS Mount.gif>)

Mounted edge: The straight edge opposite the point, with the display facing out.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

| Part | Qty |
|---|---|
| M3 x 8 mm standoff | 2 |
| M3 x 6 screw | 2 |

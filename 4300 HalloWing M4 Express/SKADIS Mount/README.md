# HalloWing M4 Express SKADIS Mount

Hangs the [Adafruit HalloWing M4 Express](https://www.adafruit.com/product/4300) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<4300 HalloWing M4 Express SKADIS Mount.gif>)

Mounted edge: The bottom edge, screwed through the two mount holes 20 mm apart, with the display facing out.

The mount holes are 3.2 mm, so use a washer under each M2 screw head.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

| Part | Qty |

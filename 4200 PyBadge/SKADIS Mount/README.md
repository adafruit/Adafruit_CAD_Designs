# PyBadge SKADIS Mount

Hangs the [Adafruit PyBadge for MakeCode Arcade, CircuitPython, or Arduino](https://www.adafruit.com/product/4200) edge-on from an IKEA SKADIS pegboard. The board screws to two M2 heat set inserts in the mount. Hole positions are checked against the Adafruit STEP model.

![Turntable render](<4200 PyBadge SKADIS Mount.gif>)

Mounted edge: The short edge by the D-pad, with the display facing out.

## Files

| File | What |
|---|---|
| `.3mf` | Ready to slice, print flat as oriented |
| `.step` | For any CAD tool |
| `.FCStd` | FreeCAD source, dimensions in the `Spreadsheet` |

## Hardware

| Part | Qty |
|---|---|
| M2 heat set insert, for a 3.3 mm hole up to 3.3 mm deep | 2 |
| M2 x 4 screw | 2 |
| M2 washer | 2 |

# P4 GPIO SKADIS Case

A two-part snap case that hangs the [P4 GPIO](https://github.com/tannewt/p4gpio) board edge-on from an IKEA SKADIS pegboard, USB-C end up. The tray holds the board and has channels for the header pins, so it works with or without headers soldered. The lid clicks over the outside of the tray walls. Large openings marked R and B give easy access to the reset and boot buttons. The fit is checked against a STEP export of the KiCad board.

![Turntable render](<P4 GPIO SKADIS Case.gif>)

## Files

| File | What |
|---|---|
| `.3mf` | Tray and lid, laid out to print with no supports |
| `.step` | Tray and lid, assembled |
| `.FCStd` | FreeCAD file with the tray and lid as solids |

No hardware needed.
